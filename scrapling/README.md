## What it does

The upstream describes Scrapling as a Python framework combining HTTP and browser-based fetching, JavaScript-rendered pages, CSS/XPath/text selectors, adaptive element tracking, concurrent spiders, proxy handling, retries, and JSON/JSONL/CSV/XML or Markdown output. It also documents a CLI, an agent skill, and an MCP server for use with AI clients.

The post's short summary broadly matches the upstream feature list. Details, compatibility, and install steps can change; use the upstream documentation for current guidance. Scraping should comply with the target site's terms, access controls, privacy requirements, and applicable law. Proxy rotation and browser automation do not grant authorization to access or collect data.

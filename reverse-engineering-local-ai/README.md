There are 36 GitHub links in the article, including a second link to REA; that leaves 35 unique repositories. ## Setup and safety notes

The X post suggests installing Ollama, pulling `dolphin3`, pointing a coding agent at that model, then running `npx rea-agents setup`. These are the post's instructions, not a setup I ran or independently verified. An existing fork of Ollama is not among the article's 36 links.

“Local” inference alone does not guarantee that everything stays on-device: the coding agent, browser/app integrations, telemetry, or enabled tools may still transmit data. Verify each component's network behavior and settings before using it with sensitive material. The quoted article frames reverse engineering as studying behavior to build your own implementation—not a license to copy proprietary code, bypass access controls, or extract private data. Respect applicable law, terms, licenses, and other users' privacy; limit testing to software and accounts you are authorized to inspect.

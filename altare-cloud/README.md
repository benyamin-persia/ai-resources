# Altare Developer Cloud

[Altare Console](https://console.altare.gg/) is the control panel for Altare, a hosted developer platform covering compute, app and game-server hosting, storage, databases, networking, and AI services. Its [official overview](https://altare.gg/en/) describes an Always Free team plan. The [pricing page](https://altare.gg/en/pricing) currently lists the plan limits; the [terms](https://altare.gg/en/terms) say limits may change and the free service has no guaranteed uptime, so check both before relying on it for anything important.

- Console: [console.altare.gg](https://console.altare.gg/)
- Product overview: [altare.gg](https://altare.gg/en/)
- Documentation: [docs.altare.gg](https://docs.altare.gg/)
- This is a hosted service, not a GitHub repository; there is nothing to fork.

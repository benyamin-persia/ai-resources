# motlab — Video as Code

Shared by [HazratCrypto on X](https://x.com/HazratCrypto/status/2123532964122214649). [motlab](https://github.com/staryone/motlab) is a code-driven video engine: an agent writes canvas-based scenes, you review and annotate frames in its viewer, and it renders an MP4 with audio. The project describes exports up to 4K and positions itself as an alternative to Remotion and HyperFrames. Its speed comparisons are project-reported benchmarks, not independently verified here.

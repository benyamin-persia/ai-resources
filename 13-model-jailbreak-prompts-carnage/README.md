# 13 Model-Specific and General-Purpose Prompt Tools — Carnage

Shared in [Carnage's X post](https://x.com/0xCarnagee/status/2126468595395731696). The post's first reply links to the [Jailbreak Every AI Model page](https://jailbreak-every-model.pages.dev/), which presents 13 copyable prompts. This page records the list and the author's stated descriptions, but does not reproduce the prompt bodies or instructions for bypassing model safeguards.

## The 13 entries, in source order

| # | Name / target | Purpose claimed by the post |
|---:|---|---|
| 1 | N3ON — Gemini 4 Neon | Model-specific persona for rebuilding apps, sites, or tools |
| 2 | S0L — GPT-6.1 Sol | Model-specific persona promising fuller answers and less hedging |
| 3 | 0PUS — Claude Opus 5.5 | Model-specific persona with role and rule rationales |
| 4 | S0NNET — Claude Sonnet 5.5 | Model-specific persona focused on complete code responses |
| 5 | F4BLE — Claude Fable 5.2 | Model-specific persona for planning, building, and checking work |
| 6 | ASTR4 — GPT-6.2 Astra | Model-specific persona promising fewer lectures |
| 7 | GOD MODE | N3ON variant advertised with persistent memory |
| 8 | Grok Bot | Standing instructions advertised for a Grok bot |
| 9 | The Last Prompt | General-purpose, six-mode prompt |
| 10 | The Tuner | Prompt adaptation and testing workflow |
| 11 | Refusal Rescue | One-line response to a refusal described as false |
| 12 | Show Me The Line | Requests disclosure of content the model omitted or softened |
| 13 | Disclaimer Trimmer | Requests fewer caveats and disclaimers |

These are the names and claims from the post, not independently tested capabilities. A prompt cannot guarantee factual accuracy, reliable code, persistent memory, or a change to a model's system-level behavior. Keep any use within the model provider's rules and applicable law; refusal or safety messages may be there for substantive reasons, not merely as boilerplate.

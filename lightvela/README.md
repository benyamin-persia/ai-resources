# LightVela — Cloud-Hosted Personal AI Agent

Shared by [HShaabani on X](https://x.com/HShaabani/status/2125754893172699233). The post points to [LightVela](https://lightvela.ai/), a hosted service for deploying always-on personal AI agents.

According to [LightVela's documentation](https://lightvela.ai/docs/overview), its agents currently run on Hermes Agent in a managed cloud environment. The product offers a web chat and integrations with messaging services, configurable models and skills, and persistent memory. Current plans, credits, and pricing are subject to change; check the [plans page](https://lightvela.ai/subscribe) before signing up.

This is a hosted service, not a GitHub repository, so there is nothing to fork. Its [privacy policy](https://lightvela.ai/privacy-policy) says prompts, outputs, and message-relay data are processed, with personal information stored on servers in Singapore. Review the policy, terms, model/provider data handling, integrations, and permissions before connecting accounts or relying on it for actions.

# HA-MCP — Home Assistant MCP Server

Shared in [HazratCrypto's X post](https://x.com/HazratCrypto/status/2122717083817418774), which includes a [short demo video](https://x.com/HazratCrypto/status/2122717083817418774/video/1).

The post describes `ha-mcp` as an MCP server that lets AI assistants work with Home Assistant—controlling devices, creating automations, and building dashboards. It claims 86 tools, free use, and installation through the Home Assistant Marketplace on version 2026.11. These figures and compatibility statements are claims from the post; check the current project documentation and release notes for exact capabilities and requirements.

- Upstream: [homeassistant-ai/ha-mcp](https://github.com/homeassistant-ai/ha-mcp)
- Your individual fork: [benyamin-persia/ha-mcp](https://github.com/benyamin-persia/ha-mcp)

The post says its caveat is in the first comment, but that comment was not available in the source retrieved for this entry. Because this integration can expose controls over real devices and home automations, review permissions and tool access before connecting an assistant, and test changes safely.

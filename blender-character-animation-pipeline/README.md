# Blender Character-Animation Pipeline — 10 Projects

Collected from [Keno's X post](https://x.com/kenonews/status/2123447398257017308) and its continuation replies. The workflow spans character creation, rigging and motion capture, motion generation, voice, lip sync, and avatar export. Descriptions below summarize the post's project labels; check upstream docs for current capabilities, setup, and licensing.

## Build and rig characters

- [MPFB](https://github.com/makehumancommunity/mpfb2) → [your fork](https://github.com/benyamin-persia/mpfb2) — create human bodies, faces, and rigs in Blender.
- [Puppeteer](https://github.com/Seed3D/Puppeteer) → [your fork](https://github.com/benyamin-persia/Puppeteer) — automated rigging and animation for 3D models.

## Capture or generate motion

- [FlowHMR](https://github.com/flowhmr/flowhmr) → [your fork](https://github.com/benyamin-persia/flowhmr) — estimate 3D motion from video and export motion data.
- [FreeMoCap](https://github.com/freemocap/freemocap) → [your fork](https://github.com/benyamin-persia/freemocap) — markerless motion capture from cameras.
- [MediaPipe](https://github.com/google-ai-edge/mediapipe) → [your fork](https://github.com/benyamin-persia/mediapipe) — camera-based tracking tasks, including hands and face.
- [HY-Motion 1.0](https://github.com/Tencent-Hunyuan/HY-Motion-1.0) → [your fork](https://github.com/benyamin-persia/HY-Motion-1.0) — generate 3D human motion from text prompts.
- [Rokoko Studio Live for Blender](https://github.com/Rokoko/rokoko-studio-live-blender) → [your fork](https://github.com/benyamin-persia/rokoko-studio-live-blender) — bring motion-capture data into Blender rigs.

## Voice, lip sync, and avatar export

- [Kokoro](https://github.com/hexgrad/kokoro) → [your fork](https://github.com/benyamin-persia/kokoro) — text-to-speech model for character voice.
- [Rhubarb Lip Sync](https://github.com/DanielSWolf/rhubarb-lip-sync) → [your fork](https://github.com/benyamin-persia/rhubarb-lip-sync) — generate mouth-shape cues from voice recordings.
- [VRM Add-on for Blender](https://github.com/saturday06/VRM-Addon-for-Blender) → [your fork](https://github.com/benyamin-persia/VRM-Addon-for-Blender) — import, export, and edit VRM avatars in Blender.

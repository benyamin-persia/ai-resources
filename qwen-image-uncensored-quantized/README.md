# Qwen Image 2.1 Uncensored Omni Quantized

Model page shared in [0xhaziq's X post](https://x.com/0xhaziq/status/2122486813080367176) and [WojakTheDev's post](https://x.com/WojakTheDev/status/2122581216251748624): [chatrlabs/Qwen-Image-2.1-Uncensored-Omni-Quantized](https://huggingface.co/chatrlabs/Qwen-Image-2.1-Uncensored-Omni-Quantized).

The post describes a 4.47 GB Q4_K_M model for local text-to-image generation and image editing, with ComfyUI GGUF support and no access gate. These specifications and availability statements come from the post; check the model card for current files, license, hardware requirements, and usage details.

This is a Hugging Face model repository rather than a GitHub repository, so there was nothing to fork.

WojakTheDev's post also cites 37K+ downloads and rounds the model size to 4.4 GB. These are additional claims from that post, not independently verified.

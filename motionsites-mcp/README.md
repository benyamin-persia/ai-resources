# MotionSites MCP

Shared by [Code Cloud's X post](https://x.com/codecloude/status/2126063183064351094), which quotes [Viktor Oddy's walkthrough](https://x.com/viktoroddy/status/2125553641956462678). This is MotionSites' remote MCP connector for design prompts, distinct from its [Studio site-building service](https://studio.motionsites.ai/) and the general [MotionSites prompt library](https://motionsites.ai/), already listed in the [AI design websites collection](../8-ai-design-websites/README.md).

The [official MCP page](https://motionsites.ai/mcp) says the connector works with Claude, Claude Code, Cursor, and Codex. It connects to `https://motionsites.ai/api/mcp` and requires signing in to authorize access. The current offer is free to connect and allows free accounts to open three prompts; paid plans unlock the larger prompt library. The X post says the service is not free, so note the distinction: access to the full library is paid, while the official page currently advertises a limited free tier. Check current terms and pricing before subscribing.

The MCP service is hosted; the post and official setup page do not link to a GitHub server repository, so there is no GitHub repo to fork.

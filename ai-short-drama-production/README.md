# AI Short-Drama Production Projects

Shared by [Sheng Hou Xu Yao on X](https://x.com/shenghouxuyao/status/2123241101624758405). The post highlights three projects for AI-assisted short-video and drama production:

- [Pixelle-Video](https://github.com/ATH-MaaS/Pixelle-Video) → [your fork](https://github.com/benyamin-persia/Pixelle-Video) — automated short-video workflow for scripting, voice, music, and video generation. The post's link used the older `AIDC-AI` owner; GitHub currently resolves it to `ATH-MaaS`.
- [Jellyfish](https://github.com/Forget-C/Jellyfish) → [your fork](https://github.com/benyamin-persia/Jellyfish) — short-drama production workspace covering scripts, storyboards, character consistency, shot preparation, generation, and export.
- [waoowaoo](https://github.com/waooAI/waoowaoo) → [your fork](https://github.com/benyamin-persia/waoowaoo) — AI film/video production platform for character design, storyboards, and video generation.

The feature summaries reflect the post and upstream project descriptions; evaluate current capabilities, requirements, and licenses in each upstream repository.

# SceneAI Prompt Library

Website shared in [Nakamoto's X post](https://x.com/Nakamoto_2008/status/2122430234880291272): [sceneai.art](https://sceneai.art/).

SceneAI describes itself as a UI prompt library with copy-ready prompts for landing pages, animated backgrounds, and gradients. This is a website resource, not a GitHub repository, so there was nothing to fork.

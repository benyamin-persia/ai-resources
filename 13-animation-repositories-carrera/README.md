# 13 Repositories for Animation and Creative Workflows

All 13 GitHub repositories from [0xCarrera's X post](https://x.com/0xCarrera/status/2125950726136328524), preserved in the original order. Descriptions summarize the post; each entry is paired with your verified individual fork. Ten forks already existed, and three were created individually for this collection.

1. **PhotoCraft** — Free Photoshop-style editor with layers, masks, and PSD files. [storytold/photocraft](https://github.com/storytold/photocraft) → [your fork](https://github.com/benyamin-persia/photocraft).
2. **Earshot** — Create sounds from text using code. [Leonxlnx/earshot](https://github.com/Leonxlnx/earshot) → [your fork](https://github.com/benyamin-persia/earshot).
3. **Lemo-Opuscar** — A collection of cinematic looks for shots. [lemomo-ai/lemo-opuscar](https://github.com/lemomo-ai/lemo-opuscar) → [your fork](https://github.com/benyamin-persia/lemo-opuscar).
4. **OneTake** — Camera movement that glides through a scene. [feitangyuan/onetake](https://github.com/feitangyuan/onetake) → [your fork](https://github.com/benyamin-persia/onetake).
5. **3D Model Anything** — Turn a room scan into an editable 3D scene. [wesbos/3d-model-anything](https://github.com/wesbos/3d-model-anything) → [your fork](https://github.com/benyamin-persia/3d-model-anything).
6. **three.quarks** — Particle effects for Three.js. [Alchemist0823/three.quarks](https://github.com/Alchemist0823/three.quarks) → [your fork](https://github.com/benyamin-persia/three.quarks).
7. **GSAP** — Timeline-based animation. [greensock/GSAP](https://github.com/greensock/GSAP) → [your fork](https://github.com/benyamin-persia/GSAP).
8. **Three.js** — JavaScript 3D graphics for the web. [mrdoob/three.js](https://github.com/mrdoob/three.js) → [your fork](https://github.com/benyamin-persia/three.js).
9. **Blender MCP** — Connect an agent to Blender for 3D scene work. [ahujasid/mcp-for-blender](https://github.com/ahujasid/mcp-for-blender) → [your fork](https://github.com/benyamin-persia/mcp-for-blender).
10. **ComfyUI** — Node-based workflows for generative media. [Comfy-Org/ComfyUI](https://github.com/Comfy-Org/ComfyUI) → [your fork](https://github.com/benyamin-persia/ComfyUI).
11. **Taste Skill** — Agent skill for applying art direction and visual style. [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) → [your fork](https://github.com/benyamin-persia/taste-skill).
12. **HyperFrames** — Turn web pages into video shots. [heygen-com/hyperframes](https://github.com/heygen-com/hyperframes) → [your fork](https://github.com/benyamin-persia/hyperframes).
13. **Remotion** — Build videos programmatically with React. [remotion-dev/remotion](https://github.com/remotion-dev/remotion) → [your fork](https://github.com/benyamin-persia/remotion).

All 13 fork relationships were checked against their upstream repositories on GitHub.

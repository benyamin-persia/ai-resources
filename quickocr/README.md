# QuickOCR — Desktop Screen OCR

Shared by [mu4to on X](https://x.com/mu4to/status/2126001339196907836), linking [Abolfazlshahi/QuickOCR](https://github.com/Abolfazlshahi/QuickOCR). QuickOCR is an offline-first screen and clipboard OCR utility for Windows and Linux: select a screen region with a shortcut, extract its text, and copy it to the clipboard. The upstream README lists multiple OCR engines, a bundled OCRia-nano model, Persian/Arabic RTL support, and model options for multilingual OCR; choosing a hosted vision API would not be offline.

- Upstream: [Abolfazlshahi/QuickOCR](https://github.com/Abolfazlshahi/QuickOCR)
- Your individual fork: [benyamin-persia/QuickOCR](https://github.com/benyamin-persia/QuickOCR) (verified fork; parent is `Abolfazlshahi/QuickOCR`)
- License: MIT for application source. The bundled OCRia-nano model weights have a separate license; review it before reuse.

The post claims support for Persian and 90+ languages. Check the upstream README and model documentation for the current language/backend matrix and platform requirements.

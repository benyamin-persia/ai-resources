# 7 Book-Finding Websites

The seven website links from [Methcode's X post](https://x.com/Methcode/status/2124188758140473655), kept in the original order. These are websites, not GitHub repositories, so there are no forks to create.

| # | Website | Category | Description |
|---:|---|---|---|
| 1 | [ManyBooks](https://manybooks.net) | Ebooks | Ebook catalog and downloads |
| 2 | [PDF Drive](https://pdfdrive.com) | PDF search | Search for PDF books and documents |
| 3 | [PDF Coffee](https://pdfcoffee.com) | PDF sharing | Search and share PDF documents |
| 4 | [PDF Room](https://pdfroom.com) | PDF search | Search for books and documents |
| 5 | [Project Gutenberg](https://gutenberg.org) | Public-domain books | Read and download public-domain ebooks |
| 6 | [Open Library](https://openlibrary.org) | Digital library | Discover and borrow books digitally |
| 7 | [Standard Ebooks](https://standardebooks.org) | Public-domain books | Carefully formatted public-domain ebooks |

The post describes these as free book sources; that does not mean every title on every site is free to redistribute. Check the copyright status, the site's terms, and your local law before downloading or sharing a title. Catalog availability and domain behavior can also change.

# Motion Design with Fable 5.2

Beginner tutorial shared by [anstap](https://x.com/anstapnever/status/2121750611691712817): [Motion Design with Fable 5.2: from zero to your first video in 10 minutes](https://x.com/i/article/2121728254080143360).

The guide's workflow is to prompt Claude/Fable to create a self-animating HTML page, preview it in Chrome, then export frames to MP4 with FFmpeg. It demonstrates both a no-install app workflow and a Claude Code workflow, plus prompts for timing, motion, aspect ratio, revisions, and adding music. Its frame-by-frame rendering example uses Python and Playwright.

Tools mentioned in the article:

- Claude / Claude Code — write and revise the HTML animation.
- Google Chrome — preview the animation.
- FFmpeg — encode frames and combine video with audio. Your fork: [benyamin-persia/FFmpeg](https://github.com/benyamin-persia/FFmpeg).
- Python and Playwright — optional frame-by-frame browser rendering.

The article does not link to any GitHub repositories; the named tools above are described as part of its workflow, not as repositories to fork. Product/model availability, pricing, and performance claims are those made by the article and are not independently verified here.

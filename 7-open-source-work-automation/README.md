# 7 Open-Source Work Automation Projects

The seven GitHub projects shared in [Taqi Molavi's X post](https://x.com/taqimolavi/status/2124103842551718348), grouped by what they help automate. Descriptions summarize the source post and upstream project descriptions. Each upstream is paired with your individual fork.

| # | Category | Project | Upstream | Your fork |
|---:|---|---|---|---|
| 1 | Workflow automation | n8n — connect services and build automated workflows with AI capabilities | [n8n-io/n8n](https://github.com/n8n-io/n8n) | [n8n](https://github.com/benyamin-persia/n8n) |
| 2 | Short-video creation | MoneyPrinterTurbo — generate short videos from a topic or script | [harry0703/MoneyPrinterTurbo](https://github.com/harry0703/MoneyPrinterTurbo) | [MoneyPrinterTurbo](https://github.com/benyamin-persia/MoneyPrinterTurbo) |
| 3 | Document management | Paperless-ngx — scan, index, and archive documents | [paperless-ngx/paperless-ngx](https://github.com/paperless-ngx/paperless-ngx) | [paperless-ngx](https://github.com/benyamin-persia/paperless-ngx) |
| 4 | Meeting notes | Meetily — local-first meeting transcription and note-taking | [Zackriya-Solutions/meetily](https://github.com/Zackriya-Solutions/meetily) | [meetily](https://github.com/benyamin-persia/meetily) |
| 5 | Voice generation | Chatterbox — open-source text-to-speech and voice generation | [resemble-ai/chatterbox](https://github.com/resemble-ai/chatterbox) | [chatterbox-upstream](https://github.com/benyamin-persia/chatterbox-upstream) |
| 6 | Browser automation | Skyvern — automate browser-based workflows | [Skyvern-AI/skyvern](https://github.com/Skyvern-AI/skyvern) | [skyvern](https://github.com/benyamin-persia/skyvern) |
| 7 | Desktop activity & automation | Screenpipe — locally record computer activity and surface workflows for automation | [screenpipe/screenpipe](https://github.com/screenpipe/screenpipe) | [screenpipe](https://github.com/benyamin-persia/screenpipe) |

Four of the seven forks already existed (`n8n`, `MoneyPrinterTurbo`, `meetily`, and `chatterbox-upstream`). I created the other three individually (`paperless-ngx`, `skyvern`, and `screenpipe`) and verified their GitHub fork-parent metadata against the listed upstreams.

Privacy note: meeting transcription and continuous screen capture may process sensitive information. Review each project's local-processing, retention, and access-control behavior before using it with confidential data.

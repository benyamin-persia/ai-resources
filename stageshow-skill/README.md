# Stageshow — Product UI for Coding Agents

Shared by [Hamzeh UX on X](https://x.com/hamzeh_ux/status/2124078019308363779). [Stageshow](https://github.com/benjitaylor/skills/tree/main/stageshow) is a design skill for agents building product-style UI in React, including stills, feature cards, cursor demos, and bento grids. The upstream repository describes composition and motion guidance, reusable examples, and tools for capturing the result so the agent can review its work.

Install with:

```sh
npx skills add benjitaylor/skills --skill stageshow
```

Your individual fork is [benyamin-persia/stageshow-skills](https://github.com/benyamin-persia/stageshow-skills), forked from [benjitaylor/skills](https://github.com/benjitaylor/skills).

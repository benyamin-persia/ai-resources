# Model Jailbreak Prompt Collection

Repository shared in [Pengsonal's X post](https://x.com/pengsonal/status/2122567430988079507) and [Anya's X post](https://x.com/anya_yfa7/status/2122569053051015335).

- Upstream: [togg53192-cmd/jailbreaks](https://github.com/togg53192-cmd/jailbreaks)
- Your existing fork: [benyamin-persia/jailbreaks](https://github.com/benyamin-persia/jailbreaks)

The post describes a collection of model-specific jailbreak prompts and names Claude, Gemini, DeepSeek, GLM, Kimi, Qwen, Mistral, GPT-OSS, Nemotron, and Muse Spark. It advertises 32 prompts covering 26+ models; those counts and model coverage are the post's claims. The repository contains prompts intended to bypass model safeguards, so use only for authorized safety evaluation on systems you control.

Anya's post points to the same upstream and makes the same 32-prompt / 26+-model claims; no additional repositories were linked.

# 50 Useful GitHub Repositories

All 50 entries from [Taqi Molavi's X post](https://x.com/taqimolavi/status/2122720217377702056), grouped in the post's five categories and kept in its original order. Upstream links and the corresponding individual fork in your account are paired below.

I checked your GitHub account's fork parent metadata for every distinct repository: all 46 distinct repositories in this list already have individual forks, so I did not create duplicates. Entries 48, 49, and 50 repeat entries 7, 18, and 19 respectively. Entry 45 links to the DeepSeek organization, not to one repository, so it cannot be forked as a single project. The source's `ifixai-ai/iFix` URL did not resolve; the related current project is [ifixai-ai/iFixAi](https://github.com/ifixai-ai/iFixAi). Several other upstreams have moved; current canonical repositories are linked below.

# 5 AI Repositories Gaining Traction

All five projects from [Shoumya23's X post](https://x.com/Shoumya23/status/2126010943226483184), preserved in the original order. The post calls them repositories gaining traction that week; popularity metrics change over time, so no live star counts are repeated here.

1. **MiniMind** — Train small language models from scratch and explore pretraining, fine-tuning, alignment, tool use, and related workflows. Upstream: [jingyaogong/minimind](https://github.com/jingyaogong/minimind) · Your fork: [benyamin-persia/minimind](https://github.com/benyamin-persia/minimind). Apache-2.0.
2. **Last30Days Skill** — Research recent discussion across sources including Reddit, X, and YouTube. Upstream: [mvanhorn/last30days-skill](https://github.com/mvanhorn/last30days-skill) · Your existing fork: [benyamin-persia/last30days-skill](https://github.com/benyamin-persia/last30days-skill). Also cataloged under [Research](../README.md#research).
3. **Univer** — An SDK for embedding spreadsheet, document, and presentation editing, calculation, collaboration, and file-processing experiences in products. Upstream: [dream-num/univer](https://github.com/dream-num/univer) · Your fork: [benyamin-persia/univer](https://github.com/benyamin-persia/univer). Apache-2.0.
4. **Claude-BugHunter** — Claude Code skill bundle for bug bounty and security testing workflows. Use only on systems you own or are explicitly authorized to test. Upstream: [elementalsouls/Claude-BugHunter](https://github.com/elementalsouls/Claude-BugHunter) · Your fork: [benyamin-persia/Claude-BugHunter](https://github.com/benyamin-persia/Claude-BugHunter). MIT code license; its content has a separate license.
5. **FFmpeg Skill** — Agent skill for using FFmpeg in media-processing workflows. Upstream: [kajisho5/ffmpeg-skill](https://github.com/kajisho5/ffmpeg-skill) · Your existing fork: [benyamin-persia/ffmpeg-skill](https://github.com/benyamin-persia/ffmpeg-skill). MIT.

All five fork relationships were checked on GitHub. The three new forks were created individually; the other two already existed.

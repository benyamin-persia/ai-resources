# AI Jailbreak Prompt Cheat Sheet — Anastasis King

Source: [Anastasis King's X post](https://x.com/Anastasis_King/status/2126402531723252162) · [attached infographic](https://pbs.twimg.com/media/HYJ_1DgXoAABkFj.jpg?name=orig)

The post caption presents the image as an overview of AI security risks. The infographic itself is titled “AI Jailbreak Prompt Cheat Sheet” and contains ready-to-use prompts intended to bypass safeguards or extract protected information. It covers ten categories across ChatGPT, Gemini, Grok, Claude, and DeepSeek:

1. Roleplay bypass
2. System prompt disclosure
3. Safety bypass
4. Restricted content
5. Malware and exploit-code requests
6. Prompt injection
7. Identity spoofing
8. Red-team testing
9. Data extraction
10. Policy analysis

This is cataloged as a source reference, not as a validated security guide. The prompt text is deliberately not transcribed or redistributed here, especially where it requests harmful code or disclosure of private/system information. Security testing should be limited to systems you own or are explicitly authorized to assess, with a defined scope and safe test data.

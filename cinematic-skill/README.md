# Cinematic Skill — Narrated Films Built in Code

Shared by [HazratCrypto on X](https://x.com/HazratCrypto/status/2123744755628609752). [cinematic-skill](https://github.com/Moh4696/cinematic-skill) is an agent skill for creating narrated documentaries and explainers with code rather than generated video footage. The project describes a workflow for scripting, voice timing, archival imagery with license records, maps and document-style visuals, sound, and rendering. The post says it works with Codex, Cursor, and Gemini CLI; check the upstream README for current supported agents and setup requirements.

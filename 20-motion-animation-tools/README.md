# 20 Motion, Animation & Video Tools

The 20 tools and projects from [Code Cloud's X post](https://x.com/codecloude/status/2121669053332775356), organized by purpose. Every GitHub repository link in the post has been forked individually to `benyamin-persia`; links that are not GitHub repositories are included as resources without a fork. The post's “Blender Agents” link pointed to the Scenario Labs organization, so [Scenario Labs Blender Plugin](https://github.com/scenario-labs/blender-plugin) was selected as the matching agent/MCP-enabled Blender project.

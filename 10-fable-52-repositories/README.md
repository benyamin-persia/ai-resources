# 10 GitHub Repositories for Fable 5.2

All 10 repositories from [flxrnc's X post](https://x.com/flxrnc/status/2122310263575556436), in the post's original order and workflow sequence: polish → motion → 3D → visuals → captions → export. Each upstream is linked to its individual fork in `benyamin-persia`.

| # | Workflow stage | Repository | Purpose from the post | Upstream | Your fork |
|---:|---|---|---|---|---|
| 1 | Polish | Impeccable | Refine visual design and remove generic AI styling. | [pbakaus/impeccable](https://github.com/pbakaus/impeccable) | [impeccable](https://github.com/benyamin-persia/impeccable) |
| 2 | Motion | GSAP Skills | Agent skills for smooth animation from the GSAP team. | [greensock/gsap-skills](https://github.com/greensock/gsap-skills) | [gsap-skills](https://github.com/benyamin-persia/gsap-skills) |
| 3 | 3D | Three.js | Create 3D scenes that run in a browser. | [mrdoob/three.js](https://github.com/mrdoob/three.js) | [three.js](https://github.com/benyamin-persia/three.js) |
| 4 | 3D | Blender MCP | Give an agent control of Blender. | [ahujasid/mcp-for-blender](https://github.com/ahujasid/mcp-for-blender) | [mcp-for-blender](https://github.com/benyamin-persia/mcp-for-blender) |
| 5 | 3D | Anatomy | Explain machines by showing their parts. | [wheresryan22/anatomy](https://github.com/wheresryan22/anatomy) | [anatomy](https://github.com/benyamin-persia/anatomy) |

| 9 | Video | HyperFrames | Turn web pages into videos. | [heygen-com/hyperframes](https://github.com/heygen-com/hyperframes) | [hyperframes](https://github.com/benyamin-persia/hyperframes) |

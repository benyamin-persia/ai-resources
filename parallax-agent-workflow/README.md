# Parallax Agent Workflow Plugin

Shared by [HazratCrypto on X](https://x.com/HazratCrypto/status/2123551522063536466). [Parallax](https://github.com/AI4XE/Parallax) is a workflow plugin for hands-off AI coding with DeepSeek Harness, Claude Code, GitHub Copilot, and other agents. The post shows installing it as a DeepSeek Harness plugin or running its installer for Claude Code, then using the `qstart` or `wish` prompts.

Your individual fork: [benyamin-persia/Parallax](https://github.com/benyamin-persia/Parallax), forked from [AI4XE/Parallax](https://github.com/AI4XE/Parallax).

The post notes that macOS was not fully tested, GitHub Copilot supports single-agent mode only, and marketplace installation had not been tested end to end. Treat those as the poster's caveats; check the upstream README for current setup details before installing.

# React Bits

Animated, interactive React and Next.js components for text, backgrounds, cards, and other interface effects. The [project website](https://reactbits.dev) lets you preview components and install or copy their source; the upstream documents shadcn CLI and jsrepo installation options.

- Source post: [HazratCrypto on X](https://x.com/HazratCrypto/status/2124124470365364697)
- Upstream: [DavidHDev/react-bits](https://github.com/DavidHDev/react-bits)
- Your individual fork: [benyamin-persia/react-bits](https://github.com/benyamin-persia/react-bits)
- Website: [reactbits.dev](https://reactbits.dev)

The post describes the collection as free and open source and highlights JS/TS and CSS/Tailwind variants plus shadcn MCP discovery. Check the upstream repository for current component availability, installation instructions, and licensing. The post also mentions a caveat in its first comment; that comment is not included here, so consult the source thread for it.

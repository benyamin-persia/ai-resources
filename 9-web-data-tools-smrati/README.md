# 9 Open-Source Web Data and Research Tools

All nine repositories from [Smrati Tiwari's X post](https://x.com/smratitiwa86867/status/2126017593874194916), preserved in the original order. Every upstream is paired with your verified individual fork. Two forks already existed; seven were created individually for this post.

| # | Project | Purpose | Upstream | Your fork |
|---:|---|---|---|---|
| 1 | Firecrawl | Crawl websites and return structured, LLM-ready web content. | [firecrawl/firecrawl](https://github.com/firecrawl/firecrawl) | [benyamin-persia/firecrawl](https://github.com/benyamin-persia/firecrawl) |
| 2 | Crawl4AI | Crawl and extract web content for AI and data workflows. | [unclecode/crawl4ai](https://github.com/unclecode/crawl4ai) | [benyamin-persia/crawl4ai](https://github.com/benyamin-persia/crawl4ai) |
| 3 | Scrapy | Python framework for building and running web crawlers. | [scrapy/scrapy](https://github.com/scrapy/scrapy) | [benyamin-persia/scrapy](https://github.com/benyamin-persia/scrapy) |
| 4 | Playwright | Browser automation for Chromium, Firefox, and WebKit. | [microsoft/playwright](https://github.com/microsoft/playwright) | [benyamin-persia/playwright](https://github.com/benyamin-persia/playwright) |
| 5 | Browserless | Browser infrastructure and APIs for remote browser automation. | [browserless/browserless](https://github.com/browserless/browserless) | [benyamin-persia/browserless](https://github.com/benyamin-persia/browserless) |
| 6 | Newspaper4k | Extract article text and metadata from news sites. | [AndyTheFactory/newspaper4k](https://github.com/AndyTheFactory/newspaper4k) | [benyamin-persia/newspaper4k](https://github.com/benyamin-persia/newspaper4k) |
| 7 | Trafilatura | Extract main text, metadata, and related information from web pages. | [adbar/trafilatura](https://github.com/adbar/trafilatura) | [benyamin-persia/trafilatura](https://github.com/benyamin-persia/trafilatura) |
| 8 | Oxylabs Web API MCP | MCP server connecting AI agents to Oxylabs web data APIs. | [oxylabs/web-api-mcp](https://github.com/oxylabs/web-api-mcp) | [benyamin-persia/web-api-mcp](https://github.com/benyamin-persia/web-api-mcp) |
| 9 | Colly | Fast web-crawling framework for Go. | [gocolly/colly](https://github.com/gocolly/colly) | [benyamin-persia/colly](https://github.com/benyamin-persia/colly) |

Use these tools in accordance with applicable site terms, access controls, and data-protection requirements.

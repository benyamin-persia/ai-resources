# Orca — Parallel Coding-Agent Fleet

Shared by [ToPassTheTimee on X](https://x.com/ToPassTheTimee/status/2125998021334736948), linking [stablyai/orca](https://github.com/stablyai/orca). Orca is an open-source desktop app for running and coordinating coding-agent bots, including Claude Code and Codex, across worktrees and local or remote machines. Its README also describes mobile apps for monitoring and steering agents, chat/terminal workflows, integrations, and parallel task delegation.

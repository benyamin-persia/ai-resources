# AI Learning Resources from Companies

Shared by [Methcode on X](https://x.com/Methcode/status/2124087801360654801) and [Nakamoto_2008 on X](https://x.com/Nakamoto_2008/status/2125523249174077609) as company-provided ways to learn AI and related developer skills:

- [Anthropic Academy](https://anthropic.skilljar.com) — Anthropic's Skilljar learning portal. The page could not be inspected during this check, so verify current course availability directly.
- [Google AI training](https://grow.google/ai) — courses and training for practical AI skills, from introductory material to professional training.
- [Meta AI resources](https://ai.meta.com/resources/) — Meta's broader collection of frameworks, tools, models, datasets, demos, system cards, and publications; not solely a course catalog.
- [NVIDIA CUDA](https://developer.nvidia.com/cuda) — CUDA developer platform, toolkit, documentation, and learning resources for GPU-accelerated computing.
- [Microsoft Learn](https://learn.microsoft.com/en-us/training/) — Self-paced learning paths, modules, and courses, including technical and AI topics. Check individual offerings for current costs; training and certification exams may have different pricing.

The posts describe these resources as free. Availability, enrollment requirements, and which specific offerings are free can vary; check each provider's current page. Nakamoto_2008's post says “10” companies, but the retrieved post contains only four URLs; Anthropic, Google, and NVIDIA were already listed here, and Microsoft Learn was the additional link. No other six URLs were present in that post to add. These are websites, not GitHub repositories, so there was nothing to fork.

# AI Learning Resources from Companies

Shared by [Methcode on X](https://x.com/Methcode/status/2124087801360654801) as company-provided ways to learn AI and related developer skills:

- [Anthropic Academy](https://anthropic.skilljar.com) — Anthropic's Skilljar learning portal. The page could not be inspected during this check, so verify current course availability directly.
- [Google AI training](https://grow.google/ai) — courses and training for practical AI skills, from introductory material to professional training.
- [Meta AI resources](https://ai.meta.com/resources/) — Meta's broader collection of frameworks, tools, models, datasets, demos, system cards, and publications; not solely a course catalog.
- [NVIDIA CUDA](https://developer.nvidia.com/cuda) — CUDA developer platform, toolkit, documentation, and learning resources for GPU-accelerated computing.

The post describes these resources as free. Availability, enrollment requirements, and which specific offerings are free can vary; check each provider's current page. The post links to websites, not GitHub repositories, so there was nothing to fork.

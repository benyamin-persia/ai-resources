# Blender Skills — Agent Skill Pack

Shared by [HsiangHui on X](https://x.com/hsianghui/status/2125945423508762903), linking [arjun988/blender-skills](https://github.com/arjun988/blender-skills). The upstream repo describes 94 Blender skills for Cursor, Claude Code, Kiro, and Codex, covering modeling, hard-surface work, retopology, UVs, materials, rigging, animation, and export pipelines for Unreal, Unity, and Godot.

The skills execute through a connected Blender MCP setup; the upstream quickstart requires Blender and its BlenderMCP add-on. Follow the repository's setup guide for client-specific installation and compatibility details.

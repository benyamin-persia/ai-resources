# 12 Repositories for Motion Video Production

The 12 GitHub repositories listed in [0xrivvian's X post](https://x.com/0xrivvian/status/2122256587762831613), kept in the post's original order. Together they cover topic-to-video generation, animation, editing, motion graphics, captions, and export. Each upstream is paired with its fork in `benyamin-persia`.

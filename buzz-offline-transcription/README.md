# Buzz — Offline Audio and Video Transcription

Shared in [Arash's X post](https://x.com/webmasterarash/status/2125575373760901620), which describes Buzz as a free offline transcriber and says it handles Persian. Buzz is an MIT-licensed desktop application built on Whisper. Upstream lists audio/video files and YouTube links, live microphone transcription, speaker identification, and TXT/SRT/VTT exports. Transcription quality varies with model, language, recording, and hardware; the post's Persian claim is not an accuracy guarantee.

- Upstream: [chidiwilliams/buzz](https://github.com/chidiwilliams/buzz)
- Your individual fork: [benyamin-persia/buzz](https://github.com/benyamin-persia/buzz)
- Upstream docs: [chidiwilliams.github.io/buzz](https://chidiwilliams.github.io/buzz)
- License: MIT

The upstream README documents installers for Windows and Linux, a macOS app (current versions require Apple silicon), and a Python package. It does not document an Android/Termux install path, so this may not run directly in your current Termux setup.

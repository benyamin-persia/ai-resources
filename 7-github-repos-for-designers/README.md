# 7 GitHub Repositories for Designers

The **7 repositories** from [kiosa's X post](https://x.com/thegreatest_sv/status/2116587002493542781), published October 31, 2026, in the order shared.

Descriptions below summarize the post and current GitHub repository descriptions. All seven repositories were checked on November 1, 2026. The Motion Design Skill also appears in the [AI Motion Graphics & Video Production](../README.md#ai-motion-graphics--video-production) section, so it is cross-linked there to avoid duplicating its main listing.

| # | Repository | Category | Purpose |
| --- | --- | --- | --- |
| 1 | [Graphify](https://github.com/Graphify-Labs/graphify) | Design context & memory | Build a queryable knowledge graph from a codebase and its documentation, schemas, configs, and PDFs. |
| 2 | [Awesome DESIGN.md](https://github.com/VoltAgent/awesome-design-md) | Design systems | Collect brand design systems in `DESIGN.md` format for coding agents. |
| 3 | [Hallmark](https://github.com/Nutlope/hallmark) | UI design skills | An anti-AI-slop design skill for Claude Code, Cursor, and Codex. |
| 4 | [Huashu Design](https://github.com/alchaincyf/huashu-design) | Generative design | Create web and app prototypes, editable presentations, animations, and infographics from prompts. |
| 5 | [Designer Skills Pack](https://github.com/Owl-Listener/designer-skills) | Design agent skills | Agent skills, commands, and plugins for research, design systems, UI, interaction, and delivery. |
| 6 | [Motion Design Skill](https://github.com/LottieFiles/motion-design-skill) | Motion design skills | Teach agents motion principles including timing, easing, and choreography. Already listed in the motion graphics collection. |
| 7 | [Blender Agent Skills](https://github.com/EL4CTEO/blender-skills) | 3D design skills | Blender workflows for modeling, materials, rigging, animation, rendering, and export. |

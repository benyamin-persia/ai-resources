# NVIDIA SkillEvaluator

Repository shared in [HazratCrypto's X post](https://x.com/HazratCrypto/status/2122265515481497873).

- Upstream: [NVIDIA/SkillEvaluator](https://github.com/NVIDIA/SkillEvaluator)
- Your fork: [benyamin-persia/SkillEvaluator](https://github.com/benyamin-persia/SkillEvaluator)

Install and run the example validation command shown in the post:

```bash
pip install skillevaluator
skillevaluator validate ./my-skill --tiers 1
```

The post says a sample skill scored 86/100 against a passing threshold of 70, and that the tool works with Codex and OpenCode without cloud usage. It also cautions that full testing requires Docker and a model API key, which may incur costs, and that the project is experimental without official support. These scores, compatibility details, and caveats are recorded as claims from the post.

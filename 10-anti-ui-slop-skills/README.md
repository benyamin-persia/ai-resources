# 10 Skills to Reduce AI-Generated UI Slop

From [BenjaminUIX's X post](https://x.com/BenjaminUIX/status/2122286309855338953). The post recommends choosing two or three rather than installing every item. This collection keeps all ten in the original order. It links every source site and all GitHub upstreams/forks; four missing forks were created individually, and five were already present as forks.

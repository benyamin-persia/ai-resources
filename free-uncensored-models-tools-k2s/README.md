# 10 Free Uncensored Models, Tools, and Apps

Shared by [The_MissAI on X](https://x.com/The_MissAI/status/2126065549096489402). The linked [FreeUncensoredAiModel directory](https://freeuncensoredaimodel.vercel.app/) identifies K2S (@k2sbhai) as its author and says its picks were checked on November 23, 2026. This is a separate directory from [Every Free Uncensored AI Model](../uncensored-ai-free/README.md), which was shared in earlier posts.

The site's ranking, model qualities, download sizes, hardware compatibility, usage figures, and setup steps are its own claims, not independently verified here. Check current model cards, licenses, repository status, and privacy/safety requirements before use. “Uncensored” is a promotional descriptor, not a quality or safety guarantee.

4. [HauhauCS Gemma 4 E4B Uncensored](https://huggingface.co/HauhauCS/Gemma-4-E4B-Uncensored-HauhauCS-Aggressive) — listed as a 5.34 GB Q4_K_M GGUF; the directory flags Gemma-specific license terms.
5. [Dolphin Mistral 24B Venice Edition](https://huggingface.co/dphn/Dolphin-Mistral-24B-Venice-Edition) — the directory points to a community GGUF conversion by [bartowski](https://huggingface.co/bartowski/cognitivecomputations_Dolphin-Mistral-24B-Venice-Edition-GGUF).

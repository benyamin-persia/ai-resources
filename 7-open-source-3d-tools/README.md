# 7 Open-Source 3D Modeling Tools

The seven GitHub repositories from [The Greatest SV's post](https://x.com/thegreatest_sv/status/2122353750912483747), categorized by their role in a 3D asset workflow. Each upstream is paired with your individual fork.

| Category | Repository | Purpose from the post | Upstream | Your fork |
|---|---|---|---|---|
| Agent-assisted modeling | Blender MCP | Let Claude drive Blender to create models, materials, and scenes. | [ahujasid/mcp-for-blender](https://github.com/ahujasid/mcp-for-blender) | [mcp-for-blender](https://github.com/benyamin-persia/mcp-for-blender) |
| Image/text to 3D | Hunyuan3D 2 | Generate a textured 3D model from an image or text prompt. | [Tencent-Hunyuan/Hunyuan3D-2](https://github.com/Tencent-Hunyuan/Hunyuan3D-2) | [Hunyuan3D-2](https://github.com/benyamin-persia/Hunyuan3D-2) |
| Image/text to 3D | TRELLIS | Generate usable 3D assets from text or images. | [microsoft/TRELLIS](https://github.com/microsoft/TRELLIS) | [TRELLIS](https://github.com/benyamin-persia/TRELLIS) |
| Image to mesh | InstantMesh | Generate a 3D mesh from a single image. | [TencentARC/InstantMesh](https://github.com/TencentARC/InstantMesh) | [InstantMesh](https://github.com/benyamin-persia/InstantMesh) |
| Mesh cleanup | MeshAnything | Turn generated geometry into cleaner meshes. | [buaacyw/MeshAnything](https://github.com/buaacyw/MeshAnything) | [MeshAnything](https://github.com/benyamin-persia/MeshAnything) |
| Gaussian splat editing | SuperSplat | Edit 3D Gaussian splats in a browser. | [playcanvas/supersplat](https://github.com/playcanvas/supersplat) | [supersplat](https://github.com/benyamin-persia/supersplat) |
| Web 3D display | Three.js | Display interactive 3D scenes on a website. | [mrdoob/three.js](https://github.com/mrdoob/three.js) | [three.js](https://github.com/benyamin-persia/three.js) |

Four forks were created for this post; Blender MCP, SuperSplat, and Three.js were already forked in your account. The post offers to send a step-by-step tutorial to people who comment “GUIDE,” but it does not include a tutorial link.

# Huihui Qwen 3.8 27B Abliterated GGUF

Model page shared in [Nyxelarm's X post](https://x.com/Nyxelarm/status/2122701609897500837):
[huihui-ai/Huihui-Qwen3.8-27B-abliterated-GGUF](https://huggingface.co/huihui-ai/Huihui-Qwen3.8-27B-abliterated-GGUF).

The post describes this as an open-weight, abliterated Qwen 3.8 27B model distributed in GGUF quantizations, usable with Ollama, LM Studio, and llama.cpp. It also claims high download counts, no refusals, retained reasoning/coding ability, and that some quantizations run with 16 GB of VRAM. Those are claims from the post, not independently verified benchmark or hardware guarantees; check the model card and quantization details for current requirements and limitations.

This is a Hugging Face model repository, not a GitHub repo, so there was nothing to fork.

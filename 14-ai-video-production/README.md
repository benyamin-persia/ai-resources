# 14 AI Video Production Repositories

The 14 GitHub repositories listed in [0xnicc0's X post](https://x.com/0xnicc0/status/2117592218663784631), organized by their role in an AI-assisted video workflow. Each upstream is listed beside its individual fork in `benyamin-persia`.

| Category | Repository | Purpose | Upstream | Fork |
|---|---|---|---|---|
| Agent workflow | Remotion Skills | Teach agents the workflow for building videos. | [remotion-dev/skills](https://github.com/remotion-dev/skills) | [benyamin-persia/skills](https://github.com/benyamin-persia/skills) |
| 3D creation | Blender | Create 3D models, rigs, and renders. | [blender/blender](https://github.com/blender/blender) | [benyamin-persia/blender](https://github.com/benyamin-persia/blender) |
| Transcription | faster-whisper | Transcribe voiceovers into captions. | [SYSTRAN/faster-whisper](https://github.com/SYSTRAN/faster-whisper) | [benyamin-persia/faster-whisper](https://github.com/benyamin-persia/faster-whisper) |
| Voice generation | Chatterbox | Generate voiceovers from text. | [resemble-ai/chatterbox](https://github.com/resemble-ai/chatterbox) | [benyamin-persia/chatterbox-upstream](https://github.com/benyamin-persia/chatterbox-upstream) |
| Web animation | GSAP | Animate interfaces and moving text. | [greensock/GSAP](https://github.com/greensock/GSAP) | [benyamin-persia/GSAP](https://github.com/benyamin-persia/GSAP) |
| 3D agent control | Blender MCP | Let Claude operate Blender scenes. | [ahujasid/mcp-for-blender](https://github.com/ahujasid/mcp-for-blender) | [benyamin-persia/mcp-for-blender](https://github.com/benyamin-persia/mcp-for-blender) |
| Browser inspection | Chrome DevTools MCP | Inspect video output and catch mistakes. | [ChromeDevTools/chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp) | [benyamin-persia/chrome-devtools-mcp](https://github.com/benyamin-persia/chrome-devtools-mcp) |
| Media processing | FFmpeg | Inspect, convert, and export media. | [FFmpeg/FFmpeg](https://github.com/FFmpeg/FFmpeg) | [benyamin-persia/FFmpeg](https://github.com/benyamin-persia/FFmpeg) |
| Programmatic video | Remotion | Create and render videos with React. | [remotion-dev/remotion](https://github.com/remotion-dev/remotion) | [benyamin-persia/remotion](https://github.com/benyamin-persia/remotion) |
| Design quality | Impeccable | Review and polish visual design. | [pbakaus/impeccable](https://github.com/pbakaus/impeccable) | [benyamin-persia/impeccable](https://github.com/benyamin-persia/impeccable) |
| Browser 3D | Three.js | Render GPU-powered 3D in the browser. | [mrdoob/three.js](https://github.com/mrdoob/three.js) | [benyamin-persia/three.js](https://github.com/benyamin-persia/three.js) |
| Generative media | ComfyUI | Self-host image and video generation workflows. | [Comfy-Org/ComfyUI](https://github.com/Comfy-Org/ComfyUI) | [benyamin-persia/ComfyUI](https://github.com/benyamin-persia/ComfyUI) |
| Reference gathering | yt-dlp | Download reference clips and audio. | [yt-dlp/yt-dlp](https://github.com/yt-dlp/yt-dlp) | [benyamin-persia/yt-dlp](https://github.com/benyamin-persia/yt-dlp) |
| HTML-to-video | HyperFrames | Turn HTML scenes into video. | [heygen-com/hyperframes](https://github.com/heygen-com/hyperframes) | [benyamin-persia/hyperframes](https://github.com/benyamin-persia/hyperframes) |

Fork notes: the seven missing repositories were forked individually for this collection. The other six forks already existed. `benyamin-persia/Chatterbox` was already an unrelated non-fork repository, so the upstream was forked as `benyamin-persia/chatterbox-upstream` to retain both repositories without overwriting anything.

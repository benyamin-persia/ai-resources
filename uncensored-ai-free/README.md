# Every Free Uncensored AI Model

Shared in [Nakamoto_2008's X post](https://x.com/Nakamoto_2008/status/2122745724278608356) and [The_MissAI's X post](https://x.com/The_MissAI/status/2124843593298772123): [uncensored-ai-free.pages.dev](https://uncensored-ai-free.pages.dev/).

The site is a directory and hardware-based picker for open models described as having refusals removed or reduced through methods such as abliteration or fine-tuning. When checked on November 17, 2026, it advertised 103 models, including 18 said to run on a 12 GB gaming PC and 51 available through an API. It offers GPU-memory and Mac-memory filters, use-case filters, Q4 command examples, and says its scores come from the UGI Leaderboard. These counts, rankings, compatibility statements, and model descriptions are the site's claims, not independently verified here.

The X post links only to the website; it does not link a GitHub repository, so there was no repo to fork. The directory points to model downloads on Hugging Face and recommends Ollama for local use. Check each model's license, source, hardware requirements, and behavior before downloading or deploying it; model outputs can be unreliable, and trading or other consequential use needs independent testing and safeguards.

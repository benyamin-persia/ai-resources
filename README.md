### AI Motion Graphics & Video Production

Code-driven tools and agent skills for building editable animations, motion graphics, and videos. Curated from [Yarad's Claude video studio guide](https://x.com/Yarad_ai/status/2116177026927268266).

#### Video Creation and Editing

- [Remotion](https://github.com/remotion-dev/remotion) — Create and render videos programmatically with React.
- [Remotion Agent Skills](https://github.com/remotion-dev/skills) — Agent skills for planning, building, and rendering Remotion projects.
- [HyperFrames](https://github.com/heygen-com/hyperframes) — Turn HTML scenes into videos in agent-driven workflows.
- [Herk Edit Kit](https://github.com/nateherkai/herk-edit-kit) — Transcript-based video editing, short-form clips, and reusable HyperFrames templates for Claude Code and Codex.

#### Web and UI Animation

- [Motion](https://github.com/motiondivision/motion) — A modern animation library for React and JavaScript.
- [Lottie Web](https://github.com/airbnb/lottie-web) — Render lightweight After Effects animations across web and app platforms.
- [GSAP](https://github.com/greensock/GSAP) — Build precise, timeline-based JavaScript animations.

#### Motion Design Agent Skills

- [Motion Design Skill](https://github.com/LottieFiles/motion-design-skill) — Teach agents motion principles such as timing, easing, and choreography.
- [Motion Graphics](https://github.com/Barty-Bart/motion-graphics) — Create motion graphics synchronized with video transcripts using Claude Code or Codex.
- [Claude Motion Design](https://github.com/howseen-ai/claude-motion-design) — Produce code-driven promotional videos with HTML, Playwright, and FFmpeg.

#### Collections

- [Motion Graphics Skills](https://github.com/Mort1d/motion-graphics-skills) — A broader collection for creating code-based motion graphics with AI coding agents.

## Agent Skills

### Skill Libraries

- [Claude Skills Library](https://skillsclau.de/) — Browse skills by job across areas such as marketing, sales, legal, finance, and HR. The site displayed 33,971 skills when checked on November 3, 2026; email sign-in is required to download. The [individual public skill index](skillsclau.de/README.md) lists all 2,519 detail pages from its public sitemap.

### Planning & Ideation

- [Brainstorming](https://aitmpl.com/component/skill/development/brainstorming) — A structured pre-build workflow that helps an agent inspect context, clarify requirements one question at a time, compare approaches, and confirm a written design before implementation. MIT licensed; adapted from Jesse Vincent's [obra/superpowers](https://github.com/obra/superpowers/tree/2ce8aa15d05bd57213e6f746f953aafb7ded7a8b/skills/brainstorming). [Source](https://github.com/davila7/claude-code-templates/tree/main/cli-tool/components/skills/development/brainstorming) · Install: `npx claude-code-templates@latest --skill development/brainstorming`

### Design & Creative Tools

- [Graphify](https://github.com/Graphify-Labs/graphify) — Build a queryable knowledge graph from a codebase and its docs, schemas, configs, and PDFs.
- [Awesome DESIGN.md](https://github.com/VoltAgent/awesome-design-md) — A collection of brand design systems in `DESIGN.md` format for coding agents.
- [Hallmark](https://github.com/Nutlope/hallmark) — An anti-AI-slop design skill for Claude Code, Cursor, and Codex.
- [Huashu Design](https://github.com/alchaincyf/huashu-design) — Create web and app prototypes, editable presentations, animations, and infographics from prompts.
- [Designer Skills Pack](https://github.com/Owl-Listener/designer-skills) — Agent skills, commands, and plugins covering design research, systems, UI, interaction, and delivery.
- [Motion Design Skill](https://github.com/LottieFiles/motion-design-skill) — Motion principles for agents, including timing, easing, and choreography; already listed under [AI Motion Graphics & Video Production](#ai-motion-graphics--video-production).
- [Blender Agent Skills](https://github.com/EL4CTEO/blender-skills) — Blender workflows for modeling, materials, rigging, animation, rendering, and export.
- [Open 3D Skills](https://github.com/Moh4696/open-3d-skills) — Eight agent skills for Three.js scenes, scroll films, transparent video, cursor rigs, exploded views, motion assets, browser checks, and frame capture. Install with `npx skills add Moh4696/open-3d-skills` (MIT).
- [UI/UX Pro Max Skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) — Design intelligence for building polished UI/UX across multiple platforms.
